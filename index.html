Telecom NFR Standards & Reference Frameworks

Our sizing calculations strictly conform to global telecom standards and open reference architectures to ensure carrier-grade reliability (99.999% availability).

ETSI NFV (GS NFV-IFA 006 / TST 008) NFVI Dimensioning

Standardized metrics for sizing Virtual Compute, Virtual Storage, and Virtual Network resources across OpenStack and KVM-based infrastructure. Aligned with ETSI benchmarks for packet processing throughput.

GSMA Anuket (RA1 & RA2) Cloud-Native Profiles

Implementation of GSMA Anuket Reference Architectures (RA1 OpenStack, RA2 Kubernetes). Sizing models utilize Anuket standardized hardware profile sizes (Basic, Network-Intensive, Compute-Intensive).

O-RAN Alliance Acceleration Specs vRAN / DU Hardware

In-line vs Look-aside acceleration card dimensioning for O-DU and O-CU hardware. Calculates required PCIe gen4/5 lanes, FPGA/ASIC offload requirements, and Fronthaul eCPRI bandwidth allocations.

3GPP TS 28.531 / TS 23.501 5G Core CUPS Sizing

Control and User Plane Separation (CUPS) capacity mathematical formulas. Ensures independent horizontal scaling of UPF (User Plane Function) for Gbps throughput and AMF/SMF for signaling TPS.
